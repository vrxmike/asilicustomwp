# Migration Plan: Asili Gems Shop Page (No PHP/Child Theme)

This plan details how to move your `shop.html` to WordPress using the same "Neve Canvas + Custom HTML" method as the homepage. This ensures your custom design, filtering, and sorting logic remain exactly as you built them, while connecting to WooCommerce for the checkout.

## Phase 1: The "Fake Shop" Strategy

Since we cannot easily rewrite the native WooCommerce shop page layout without PHP or FSE (Full Site Editing) tools, we will create a standard WordPress Page that *acts* as your Shop.

*   **Design:** Provided by your `shop.html` (Custom HTML/CSS).
*   **Logic:** Provided by your `shop.js` (Client-side filtering/sorting).
*   **Data:** Provided by `products.js` (Static array).
*   **Checkout:** We will link the "Add to Bag" buttons to WooCommerce's built-in `?add-to-cart=ID` feature.

## Phase 2: Implementation Steps

1.  **Create a New Page:**
    *   Go to **Pages > Add New**.
    *   Title: "Shop" (or "Collection").
    *   **Template:** Select **"Neve Canvas"** (to remove default header/footer).
    *   **URL Slug:** **Crucial:** You cannot use `/shop` if WooCommerce is already using it. Name this page `collection` (e.g., `your-site.com/collection`). If you must use `/shop`, you first need to go to **WooCommerce > Settings > Products** and select a different page (or no page) for the "Shop Page" setting to free up the slug.

2.  **Add Custom HTML Block:**
    *   Paste the content of `wordpress_shop_copy_paste.html` (which I will generate for you next).

3.  **Connecting to WooCommerce (Crucial Step):**
    *   Your `products.js` file currently uses arbitrary IDs (1, 2, 3...).
    *   In WordPress, every product has a unique **Product ID**.
    *   **Task:** You must create the products in WooCommerce, get their IDs, and update the `products` array in the code block.
    *   **Code Change:** I have updated the code to look for a `woo_id` property.
    *   *Example:*
        ```javascript
        {
            id: 1,
            woo_id: 124, // <--- REAL WOOCOMMERCE ID HERE
            title: "Tanzanite Royal Pendant",
            ...
        }
        ```
    *   The "Add to Bag" button will then generate a link: `https://your-site.com/?add-to-cart=124`.

## Phase 3: Considerations

*   **Inventory:** Since the product grid is generated by JavaScript from a static list, it won't automatically hide products that are out of stock in WooCommerce. You will need to manually remove them from the code or update the code to handle "Out of Stock" status if you manually flag it.
*   **Mobile Filters:** The layout already includes mobile responsiveness.
*   **Footer/Header:** The code includes your custom Header and Footer.

## Phase 4: Execution

I will now generate the `wordpress_shop_copy_paste.html` file. This file will contain:
1.  All CSS (`palette`, `style`, `shop`).
2.  The Shop HTML structure.
3.  All JS (`products`, `app`, `shop`), **modified** to generate functional Add-to-Cart links.
